# Prereg: Appendix D precision bookkeeping (D.11) of the ETH preprint
Written 2026-10-28 before the dedicated analysis (D.11 and its two-paragraph proof were read once while modeling the exponent; the lemma D.5 recovery was tested separately). Claims: along an active recursion path with depth-d parameters u_d = floor(eps lambda/2^d), a_d = 2 sum_{j<=d} u_j (a_{-1} = 0), L = 2^{a_d}, M_d <= C s 8^{-d}, h = ceil(3M/u): the input precision satisfies p <= s lambda^{O(1)} 2^{a_{d-1}}, and for every node t with q_t > 0 the child precision p_t = p + 8 h D_t + 8 M (a+1) = O_C(M D_t/u). Proof sketch (as written): root P0 <= Cs; increments 8hD_t + 8M(a+1) with h <= 4M/u, M <= Cs, D_t <= 2^{a_d}, summed over O(log lambda) depths; for the second claim q_t > 0 implies i < u so D_t >= 2^{a_d - u} = 2^{a_{d-1} + u}; since M > H = ceil(s/floor(sqrt lambda)) and u >= lambda^{4/5}, the extra factor 2^u dominates every fixed power of lambda; the increment 8hD_t is O(M D_t/u) directly. All precisions remain polynomial in s since a_d <= 4 eps lambda.
Predictions:
- PB-1: the proof re-derives; the first assertion only needs depth count O(log lambda) times s 2^{a_{d-1}}, i.e. lambda^{O(1)} is really O(log lambda)-ish.
- PB-2: a log-domain simulation of the exact recursion p_{d+1} = p_d + 8 h D_max + 8 M (a_d+1) (worst case M_d = C s 8^{-d}, D_max = 2^{a_d}) confirms p_d <= s 2^{a_{d-1}} * (small polynomial in lambda) at every depth, for lambda from 1e7 to 1e300.
- PB-3: the second assertion (p_t <= K M D_t/u with K = 24 + o(1)) holds in the worst case (M just above H, i = u - 1) exactly from a lambda_1 that is far below the literal reading of (D.5) (u >= lambda^{4/5} needs lambda >= ~2^{546}); I expect lambda_1 in the 1e9-1e11 range (set by 2^{u_min} >= 32 C (d+1) sqrt(lambda) u).
- PB-4: bits of precision stay polynomial: log2 p_d <= (1 + 4 eps) lambda + O(log lambda).
- PB-5: no gap; the one place the text is loose is writing lambda^{O(1)} for what is a O(log lambda) factor and invoking u >= lambda^{4/5} where u >~ log lambda suffices.
Method: log2-domain recursion for C in {12, 144}; compute for each lambda and depth the quantities above; find lambda_1; evaluate the (D.5) literal threshold.
