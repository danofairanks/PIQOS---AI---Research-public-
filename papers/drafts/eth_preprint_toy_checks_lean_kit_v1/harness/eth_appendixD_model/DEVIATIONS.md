# Deviations / notes (eth_appendixD_model)
- G-1 Correction of my own reading: the prereg and RESULTS_eth_paper.md first stated Theorem 1.1's general-density exponent as n sqrt(loglog n)/sqrt(log n). The rendered pages (2, 57) show n loglog n / sqrt(log n) (extraction drops radicals). Corrected in RESULTS_eth_paper.md. Prereg prediction D-6 rested on the wrong form and is scored as such.
- G-2 Leading-order explicit constants only. From D.4.2-D.4.5: leaf cost 2^H with H = s/floor(sqrt(lambda)); active level d has M_d <= C s 8^{-d} edges (the paper's invariant; the text's sharper 3M/r = 3M/32 is not used), u_d = eps*lambda/2^d, eps = 1/(128*1024), r = 64; number of child tuples bounded by exp(theta p_t + (6M/D_t) sum_j -ln(1-e^{-theta j})) <= exp(2 pi sqrt(M p_t/D_t)) (optimized theta; sum 1/h^2 = pi^2/6); p_t = p + 8 h D_t + 8M(a+1) with h = ceil(3M/u); the inherited p and 8M(a+1) terms are o(24 M D_t/u) by the paper's own estimate, so p_t ~ 24 M D_t/u and ln N_d <= 2 pi sqrt(24) M_d / sqrt(u_d). The O(.) in exp(O_C(M/sqrt u)) is replaced by this derived bound; the paper itself writes only O_C.
- G-3 Total per-s exponent: H + sum over active levels (M_d > H) of ln N_d / ln 2. Per-level factors r (=64) groups, interpolation values (< s^4 each) and polynomial factors contribute O(lambda log lambda) bits total (paper's own accounting) and are dropped. Entry-evaluation cost exp(O(s^{9/10})) dropped (paper: absorbed).
- G-4 C (edges per s). Clause-network branch: edges <= 4 k m (one tree edge-set per variable, each edge subdivided once; I dropped a -6n correction), s = n+m, C = 4kD/(1+D). Parity branch: size parameter s = n nu; wires M <= J^2 + K log2(e(N+K)/K) with K = k(a + 2(l-1)) = 8kn (a <= 6n), N <= a * k lambda^c with lambda^c ~ 2^k max(P, D0) (the paper's monomial-count bound), D0 = 320000 B^2 mu^3 with B, mu from sigma = 1/ceil(sqrt(lambda)); J^2 = O(sqrt n) dropped. So C = 8k (log2 D0 + k + 1.03)/nu.
- G-5 Parity-branch totals add sigma = 1/ceil(sqrt(lambda)) (tree 2^{sigma n}) and the branching 1/sqrt(lambda) (D.2: <= n/sqrt(lambda) high-incidence variables). Degree arrays 2^{O(sqrt n log n)} dropped.
- G-6 lambda for the contraction (lambda = ceil(log2 s), s = n nu) is approximated by lambda = ceil(log2 n).
- G-7 Validity threshold. (D.5) states u >= lambda^{4/5} for sufficiently large s. At the last active level u = eps lambda^{5/6}/C^{1/3}, so the literal inequality needs lambda >= (C^{1/3}/eps)^30 ~ 2^546..2^582. The paper uses u only to absorb inherited precision against lambda^{O(1)} (needs u >~ c0 log lambda, a much weaker condition, whose constant c0 is not given), so I do NOT claim the proof fails below that; the model is evaluated at lambda ~ 1e10..1e16 on that basis. The threshold for "sufficiently large" is unspecified in the paper.
