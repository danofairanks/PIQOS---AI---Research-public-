# Deviations / notes (eth_sparsification_model)
- F-1 Entropy-level model as in eth_cost_model (poly factors dropped; log2(2D+1) ~ 1+log2 D). Per-n exponent total = sigma + 1/sqrt(lambda) [branching on |S| <= n/sqrt(lambda) high-occurrence variables, Sec 5.5] + (1 - 1/sqrt(lambda)) * (e1 + e2 + e3) [Prop 5.3 cost on n' ~ n(1-1/sqrt(lambda)) free variables].
- F-2 Sparsification tree: s = floor(sqrt(lambda)/nu^2), sigma = 1/s; M = least power of two >= Gamma with Gamma*h <= sigma*M, h = ceil(log2(4CM)), C = 4 sum_{j=0}^{k-2} (3M)^j, Gamma = 2(3^{k-1}-1) (Appendix A.3); B = 2 sum_{j<k} M^j (leaf occurrence bound). Exact integer arithmetic.
- F-3 My derivations (not stated by the paper) that set beta: scope w <= k*max(D0,P) (an equation is a parity of <= max(D0,P) clauses, each on <= k variables; D0 = 320000 B^2 mu^3, P = 20000 B^2 mu^2, mu = floor(log2 m)+1 <= lambda + log2 B + 1); incidences M_inc <= 6n*w + n so b0 = ceil((6w+1) sqrt(lambda)); beta = least integer with b0 <= lambda^beta. The paper says only "b and w are bounded by a fixed power of log n'". A constant-factor change in w or b0 can move beta by one (see step at k=3).
- F-4 Taylor term: delta = d_H/(Q n') with d_H = k R (m_test + 2(l-1)), m_test <= 6n (Lemma 6.2: <= 6n equations), l = n+1 (Sec 5.1), R = (beta+3) ceil(sqrt(lambda)) (Lemma 4.8). So delta ~ 8k(beta+3)*128 nu / sqrt(lambda) (vs 3*4*128 nu/sqrt(lambda) in the base-case model). lambda, nu taken for n rather than n' ~ n(1-1/sqrt lambda) (negligible difference).
- F-5 Not modeled (stated as negligible, checked by inspection of magnitudes, not by code): the exp(polylog) overheads: 3n(2m)^P+1 candidate counts, exp(poly(B,log m)) matrix searches (2^{D0^2/(8B)}-type), all polynomial in lambda against n = 2^lambda.
- F-6 Crossover reported is the first grid-refined lambda where total < 1 and no re-crossing in 5000 samples above. Because beta is an integer step function of lambda, the total jumps at a beta change (k=3: beta 7 -> 6 at lambda ~ 3.4774e13, total 1.02 -> 0.955). The k=3 value is therefore a step location, not a smooth zero.
- F-7 Lemma 6.1/6.2 internals (Tanner code existence, conditional-expectation argument) and the disjointness proof in Appendix A are read, not re-derived; only their stated sizes feed the model.
