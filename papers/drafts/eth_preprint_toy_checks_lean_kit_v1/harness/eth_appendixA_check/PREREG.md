# Prereg: Appendix A (disjoint sparsification, tree-size proof) of the ETH preprint
Written 2026-10-28 before the dedicated re-derivation and numerics (Appendix A text was read once while modeling the sparsification step). Claims: branching rule (A.1) on a shared literal set H with deg_c(H) >= theta_{c-|H|} = M^{c-|H|} (smallest c, then largest |H|); children F_A = G ^ H, F_B = G ^ (and P_a) ^ (and not-l for l in H) partition the satisfying assignments; Lemma A.1 (new clauses survive normalization, removed clauses contain a new strict subset); Lemma A.2 (fewer than 2 theta_{j-i} marked width-j clauses contain any size-i literal set); Lemma A.3 (T_j <= 4 (3M)^{j-1} n along a path); tree size <= (Cn+1)^2 2^{(Gamma n/M) log2(4CM)} with C = 4 sum_{j<=k-2}(3M)^j, Gamma = 2(3^{k-1}-1), M >= Gamma; leaves have occurrence bound B = 2 sum_{j<k} M^j <= 4 M^{k-1}.
Predictions:
- A-1: every step of Lemmas A.1-A.3 and the node-count combinatorics re-derives on paper (A.2: the case analysis for child A and child B uses the smallest-width and largest-|H| priorities; A.3: the induction closes with 4*3^{j-1}).
- A-2: an implementation of the branching algorithm on random dense k-CNFs (k = 3, n <= 14, M in {2,3,4,16}) shows: (i) children partition satisfying assignments exactly (every assignment satisfies exactly one leaf iff it satisfies F; leaf counts sum to #F); (ii) T_j <= 4(3M)^{j-1} n on every path; (iii) the Lemma A.2 invariant holds at every node; (iv) path depth <= Cn and B-choices <= Gamma n/M; (v) leaf variable occurrence <= B.
- A-3: for M >= Gamma = 16 (k = 3) the realized node counts are far below (Cn+1)^2 2^{(Gamma n/M) log2(4CM)} (huge slack).
- A-4: the combinatorial inequality sum_{a <= floor(Gamma n/M)} binom(Cn,a) <= 2^{(Gamma n/M) log2(4CM)} holds exactly for n in 1..200, M in {16, 32, 64}, k in {3,4}.
- A-5: no gap found; the subtle points to inspect are: (a) a branch whose selected H has |H| = 1 inserts a unit clause H in child A, counted in T_1 with units never deleted; (b) 'present clauses are not unit-propagated', so a leaf can contain contradictory unit pairs {l},{not l}; (c) the leaf occurrence bound counts at most one unit clause per literal.
Method: re-derive; implement; run; log any deviation (e.g. M smaller than Gamma for the lemmas that hold for any M >= 2).
