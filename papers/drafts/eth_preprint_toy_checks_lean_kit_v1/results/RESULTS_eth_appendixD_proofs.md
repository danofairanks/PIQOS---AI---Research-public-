## Re-derivation by reading
- **D.3:** E sum_gamma (X_gamma - M/D_arr)^2 = sum over ordered edge pairs of (P[equal labels] - 1/D_arr); disjoint-endpoint pairs have probability exactly 1/D_arr, pairs sharing an endpoint number at most 2 M Delta (each edge has two endpoints of degree <= Delta), each contributes <= 1: so <= 2 M Delta; conditional expectations give a labeling with sum (X_gamma - M/D_arr)^2 <= 2 M Delta, so every load <= M/D_arr + sqrt(2 M Delta) <= 2M/D_arr when M >= 2 D_arr^2 Delta (equivalent), and rounding up to a multiple of L adds <= L <= M/D_arr (M >= L D_arr): H_pad <= 3M/D_arr; packets: H_pad D_arr/L <= 3M/L; per coordinate/symbol: 1/r of all pair-labels, so <= H_pad D_arr/r <= 3M/r real ports. Packet assembly uses 2^{a-a'} slots from each of 2^{a'} ordered labels of an unordered-symbol class (a' unequal coordinates), so L = 2^a slots, orientation bits = slot bits on unequal coordinates, copy index on equal ones. All steps close.
- **D.4:** W_xy(T) = prod_{q != y-x}(T - q)/C'(0). W(0) = I (zero factor in every term except y = x). v2(C'(t)) = v2(C'(0)) because S is a complete residue system mod 2^{a+1} with |t - q| <= 2L - 1 < 2^{a+1}, so the multiset of valuations of t - q does not depend on t. Entries of C(t+alpha z)/C'(0) have valuation >= a+1; removing the factor q = y - x costs <= a (if t != y-x) or removes alpha z (if y-x = t). So W(t + alpha z) is 2-adically integral, and divisible by 2 when y - x != t.
- **D.5:** sum_{t != 0} q_t >= (L odd points) h u >= 3 M L > M (2L - 1); h <= 4M/u, q_t <= 4M. Hermite formula (D.9) is the CRT form with node multiplicities q_t; each E_t(t+alpha z) factor is 1 + alpha z/(t-q), 2-adically integral with constant term 1, so dividing loses no precision; v2(E_t(0)) >= -6 D_t h from the valuation count (D.10); evaluating a polynomial of degree < q_t <= 4M at -t/alpha loses <= 4M(a+1) powers of 2. The stated p_t = p + 8hD_t + 8M(a+1) covers both losses with margin.

## Numerics
- **D.4, a = 1..4 (L up to 16, |S| = 32), all t in S and all packet slots x,y (262,144 coefficients at a = 4):** W(0) = I; degree 2L - 1; v2(C'(t)) = v2(C'(0)) for all t; every coefficient of C(t+alpha z)/(C'(0)(t+alpha z - (y-x))) is 2-adically integral, and divisible by 2 whenever y - x != t: 0 exceptions. *Test error found and fixed:* my first version required divisibility of coefficients by the full integer C'(0) (not 2-adic integrality) and reported spurious "non-integral" counts for a >= 2; the corrected 2-adic check (valuation >= v2(C'(0))) gives 0 failures. The lemma (O = Z_(2)[U]/(f), odd denominators allowed) was never contradicted.
- **(D.10) valuations, a = 1..7, all u <= a, h in {1,2,5,11}, all t with v2(t) < u (10,328 cases):** the exact valuation sum_{q != 0,t} q_q (v2(q) - v2(t-q)) equals the closed form D sum_j (j/2^j)(q(i+j) - q(i)) in every case and satisfies >= -6 D h; the worst case reaches -5.35 D h.
- **D.5 recovery, end to end:** a in {1,2,3}, u <= a, M in {u, u+1, 2u+1, 5}, p in {1,3,8}, random integer polynomials F of degree M(2L-1), Taylor data truncated mod 2^{p_t}, quotient coefficients replaced by random lifts of their residues; the Hermite combination (D.9) is computed exactly in rationals. With the stated margin p_t = p + 8hD_t + 8M(a+1): recovered F(0) agrees with the true F(0) modulo 2^p in 396/396 trials, and the reconstructed sum has odd denominator (integral 2-adically). With the proof's own derived margin (6hD_t + 4M(a+1)): 396/396. With no margin (p_t = p): 0/396, so the test is sensitive. sum q_t > M(2L-1) at every tested (a, u, M).
- **D.3 packing, (r,a) in {(2,1),(2,2),(3,1)}, M = 2 D_arr^2 Delta (the smallest allowed), random bipartite multigraphs with max degree Delta = 2L (M from 128 to 4,096 edges):** derandomized vertex labeling (exact conditional expectations; initial expected potential 218-9,028, bound 2 M Delta = 1,024-65,536; realized sum of squared deviations 2-16): max load within 0.5-1.6% of M/D_arr; H_pad <= 3M/D_arr; packets 68, 333, 1,040 (bounds 192, 972, 3,072); every edge placed in exactly one slot with the same slot at both ends; orientation bits match the edges' actual (row symbol > column symbol) in every packet and unequal coordinate; real ports per coordinate/symbol 65, 218, 2,052 against 3M/r = 192, 648, 6,144.
