**T1 (CF1, augmentation equivalence).** Alphabet {g grant, r revoke, s act}; validity of a next act is a function of the whole history. Rules: A lifetime cap 3 across regrants; B no restore after any revoke; C one act per grant, lifetime (counter g−s). Naive final state = (active, spent-since-last-grant) for A, (active) for B and C.
Predictions: (a) naive final state has matched pairs (equal A_f, different correct answer) for A, B and C; (b) residual-class count (Myhill–Nerode over prefixes ≤n, suffixes ≤n, n=2..6) plateaus for A (≤8) and B (≤4) and keeps growing with n for C. Reading: bounded augmentation closes A and B (CF1 defeated at scope for them); C is the only surviving form, and C is a counter rule.
**T2 (CF2, benchmark semantics).** Matched pairs, label-from-history fraction p set by hand ∈ {0.1,0.3,0.5,0.7}; final-state reference answers continue on equal A_f. Prediction: false-continuation rate over all scenarios = p/2 ±0.02, linear in p; the reported 51.1% is reproduced at p≈1.0 under the all-scenarios denominator, and at p≈0.51 under the history-dependent-pairs-only denominator with a coin-flip reference. A rule-mined generator (pairs mined from T1 rule A random walks) gives an emergent p and the same relation.
**T3 (CF3, unspecified weights).** Two generators with different label rules (gen1: mandate/delegation changes; gen2: condition/ceiling changes), changes Poisson in elapsed time. Logistic ASD fitted on gen1 train. Prediction: ASD beats elapsed time by ≥0.02 AUC on gen1 holdout; advantage <0.02 on gen2 with gen1 weights (defeated at scope as weight-transfer claim); refit on gen2 recovers it (so the advantage is fit, not structure).
**T4 (CF4, channel).** Honest vs masking agent-reported revocation stream, independent-channel control, silent-channel default-pass. Prediction: agent-sourced masking passes N/N violating steps; independent channel 0; silent channel with default-pass passes all post-revocation continuations, default-deny passes 0.
**T5 (CF5, check-to-use + availability).** Revocation Poisson rate r per tick, check at t, effect at t+w. Prediction: unbound violation fraction ≈ 1−(1−r)^w, rising monotonically with w; version-bound 0 violations. Availability: deny-on-any-version-change false-denial rate on benign (irrelevant churn) trajectories > deny-on-relevant-change rate (0).

## Amendment 1 (2026-10-06, after the same-family blind pass; run 1 output kept as `out_run1.json`)
The blind pass found flaws in toys.py: T4 `default` arg unused (independent channel = honest agent function); T5 `bnd` hard-coded 0 (no version-bound mechanism simulated); T3 has no fixed-weights control and no elapsed-plus-change-count baseline, and ASD sees the label's coordinates by construction; T1 rule A's naive state already carries a history counter. Controls added in `toys_v2.py`; predictions fixed here before it runs:
- **T3b.** Equal-weight ASD (sum of counts, no fit) on gen1 holdout AUC below the fitted 0.952; elapsed-plus-total-count baseline within 0.02 of fitted ASD on gen2 with gen1 weights (the transferred ASD is mostly a noisy elapsed-time estimator). If so, the run-1 "defeated at scope" for CF3 stands but its stated reason (weight overfit) is wrong; the reason is common-cause leakage.
- **T4b.** Independent revocation channel with delivery delay d steps: violating steps that pass = d (so default-deny does not close a late channel).
- **T5b.** Simulated compare-and-consume against a version counter: 0 post-revocation effects with a version-honoring effector; with a third-party effector that ignores the version, violation rate equals the unbound rate 1-(1-r)^w (±0.01).
Amendment 1b (before the run; T5b rewritten because the first draft of it was again tautological): three effectors. Atomic compare-and-consume: 0. Non-atomic version-honoring (reads the version, then acts; a revocation can land in the one-tick gap between read and act): violation ≈ r = 0.02 ±0.005, independent of w. Version-ignoring: equals the unbound rate 1-(1-r)^w ±0.01.

## Amendment 2 (2026-10-06, after reading the preprint's full text; written before `toys_v3.py` ran)
Purpose: run the toys against the preprint's ten mutation classes (principal, mandate, policy, delegation, condition, resource acquisition, environment, effect escalation, evidence, instruction conflict) and its depth grid D in {0,1,3,5,10,20}. **Our own implementation of the described classes, not the preprint's code (unpublished).** Ground truth is our rule, stated here: each class is a component with a visible bit v and a hidden provenance bit c; events on a component are break (v=F), restore_auth (v=T, c=T), silent_change (v=T, c=F; for instruction conflict v unchanged), or ordinary. Authorized iff v and c hold on every validity component; the evidence class is excluded from validity (it affects reconstructability only), leaving 9 validity components. Visible final state = the v bits. Because the rule is ours, every class-level result below is a property of this rule, not of the preprint's.
- **T6a (exact class counts, Moore minimization of the product automaton).** Predict: 2 residual classes per validity component (tainted and broken merge: same deny, same futures), 1 for the evidence component, 2^k for k composed validity components (k=1..4 checked: 2, 4, 8, 16). Reading: minimal sufficient statistic = one derived bit (v AND c) per component, so the augmented final state is 9 bits here.
- **T6b (generator over depth D and a silent-change weight).** Predict: final-state-only FCR is 0 at D=0 and for any D when all events are ordinary (operational depth is not authority depth); rises with D and with the silent-change weight; the 51.1% is reachable by tuning the weight (a weight within 0.05 of some value gives 0.511±0.02 at D=10), and a different weight gives under 0.2. Augmented reference (v AND c bit per component) FCR = 0 and FRR = 0.
- **T6c (strict vs class-aware revalidation).** Map break to suspend (S), silent_change to revalidate (R), restore_auth to continue (C), ordinary to N. Predict: revalidating on every non-N event gives FRR (unnecessary revalidations over all transitions) > 0.2 under a uniform mix; class-aware 0.
- **T6d (equal-final-state pairs mined from the generator).** Predict path discrimination 0 for the final-state-only reference (identity), 1.0 for the augmented bit reference, and the fraction of equal-final-state pairs with different ground truth to be reported.

## Amendment 3 (2026-10-06; written before `toys_v4.py` ran) — CF7 to CF10
All four reuse the T6 component rule and generator (D=10, authority-relevant probability 0.5, silent weight w=0.35, N=20,000, seed 7). By construction results are marked as such.
- **T7 (CF7 reconstructability).** A transition-aware reference folds an event log. (a) complete authoritative log: FCR 0, FRR 0. (b) log missing: default-allow gives the final-state-only FCR (T6: 0.234 at these settings, ±0.02); default-deny gives FCR 0 and FRR 1.0 (denies every authorized scenario). (c) agent-writable log where the agent drops each adverse event (break or silent) with probability q: FCR rises monotonically with q, 0 at q=0, 1.0 at q=1, between 0.4 and 0.8 at q=0.5. (d) two logs (authoritative complete + agent log with q=1): rule "any adverse wins" FCR 0; rule "agent log wins" FCR 1.0.
- **T8 (CF8 replay).** The independent channel is authoritative, but a replay of an old restore_auth event is appended after a later break (replay probability 0.3 per scenario when an earlier restore exists). Ground truth ignores the replay. Reference without sequence check: FCR > 0.05; with monotone per-component sequence check: 0.
- **T9 (CF9 queued effects).** One check at t0 for a queue of m=10 effects executed at t0 + i·τ (τ=5), revocation rate r=0.02 per tick. Batch check-once: violation rate at queue position i = 1-(1-r)^(iτ), mean over positions ≈ 0.33 (0.28 to 0.38), last position ≈ 0.60. Per-effect atomic compare-and-consume: 0. Per-effect non-atomic (one-tick gap): about r per effect, 0.01 to 0.025.
- **T10 (CF10 redundancy and delegation composition).** (a) Over the T6 generator, pairs equal in the augmented (v AND c) state that differ in ground truth: 0 (identity; shows H adds nothing once the maintained state carries the derived bit). (b) Delegation chain of h hops where each hop silently adds an out-of-ceiling effect with probability s=0.1: P(subset invariant violated at the leaf) ≈ 1-(0.9)^h (0.10, 0.27, 0.41, 0.65 for h = 1, 3, 5, 10; ±0.02); with enforced monotone attenuation 0.
