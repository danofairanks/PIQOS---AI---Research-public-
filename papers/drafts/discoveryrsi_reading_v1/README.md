Scripts and outputs for `discoveryrsi_reading_v1.md`.
- `predictions_fixed_2026-10-21.md`: the seven predictions, fixed after the title page, Figure 1 and abstract and before the rest of the paper was read.
- `calc.py` / `calc_output.txt`: arithmetic on numbers printed in arXiv:2610.23839v2 (Wilson intervals, naive Fisher tests, the retrieval-conditional comparison, the per-domain breakdown, the eight-axis composite and its decomposition). Standard library only. `python3 -I calc.py`.
- `quote_checks.py` / `quote_checks_output.txt`: checks that each quoted string and count in the draft occurs verbatim in the paper's text (58 of 58) and that the keyword searches the draft relies on (inter-rater, kappa, self-preference, seed, disjoint) have no hits. Needs the arXiv v2 PDF (sha256 in the script header; not stored here) and `pdftotext`.
- `repo_quote_checks.py` / `repo_quote_checks_output.txt`: checks the repository statements against single public files at the pinned commits (DiscoveryRSI 7389e0b, DFM-Bench 224712b), fetched from raw.githubusercontent.com without cloning. The test and demo runs described in section 7 of the draft were executed on 2026-10-21 and are not repeated by these scripts.
- `tool_scan_*.json`: this repository's own scanners run on the draft on 2026-10-23. `paper_rigor`: no gaps. `attractor_scan`: nothing flagged. `verification_lint`: 31 uncited-statistics matches, none severe; every one was read and is a statistic taken from the paper under reading, which the draft sources in its Sources paragraph and which `calc.py` and `quote_checks.py` re-derive.
