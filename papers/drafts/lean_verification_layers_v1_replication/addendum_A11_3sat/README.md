# Replication material for Addendum A.11 of `lean_verification_layers_v1.md`
What this folder holds: the project's own two files (`Challenge.lean`, `Solution.lean`), the Comparator config, and the logs of the runs described in A.11. It does not contain the third-party package (fetch it by the commit and zip hash given in A.11). Logs are as produced (paths are the scratch paths of the run). `04_audit_basic.log` (48 kB, 446 audit lines) is omitted here; it is in the private notes.
Files added for the second run: `comparator_config_kernels.json` (external checkers) and `11_comparator_kernels.log`.
Steps, in order: (1) fetch the package zip at the pinned commit, check its sha256 prefix and SHA256SUMS; (2) `lake exe cache get`, `lake build Credit`, the two README audit commands, `lake build Audit`; (3) add `Challenge.lean`, `Solution.lean` and two `lean_lib` entries (Challenge with `warningAsError = false`, since it contains `sorry`) to a scratch copy; (4) `lake build Challenge Solution`; (5) build Comparator from the Lean FRO repository at the commit in `comparator_commit.txt` (Lean 4.35.0) and run it with `comparator_config.json` (this run used the development shim `fake-landrun.sh`: no sandbox).
Not included, on purpose: nothing from the package is re-hosted.
