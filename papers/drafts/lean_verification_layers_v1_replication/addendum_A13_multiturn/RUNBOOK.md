# IUP-1 runbook (operator). Nothing here involves contacting anyone outside the project.
Before the first run, record in `CHOICES.md` (commit it): which pilot (`full`: 96 transcripts; `min`: 18 transcripts, one model, 6 tasks, conditions N, D, DC) and the model names/versions/tiers. The choice is not changed after the first run.
1. Generate the run sheet: `python3 make_run_sheet.py min > run_sheet.tsv` (or `full`). Keep `run_sheet.tsv` (it holds the condition key). Run the transcripts in the `run_order` given.
2. For each row: open a FRESH session of the model (no memory, no custom instructions; record the model version shown in the interface and the timestamp). Send turn 1: the script in `TASKS.md` with the row's task text. Then send turns 2 to 4 from the script of the row's condition, verbatim, one per model reply, without editing or adding anything. Do not tell the model anything else; do not answer its questions except by sending the next scripted turn.
3. Condition DC only: after each model reply except the last, copy the Lean file the model gave (the last complete file in the reply; if there is none, say "no file" to me) into `dc_files/<transcript_id>_turn<k>.lean` and send it to me; I compile it as written (Lean 4.27.0-rc1, Mathlib fdddb3ea, full output) and return the exact compiler output. Paste it verbatim into the next turn after "Compiler output follows:". Do not summarize or trim it.
4. Save each transcript verbatim as `transcripts/<transcript_id>.md` using `TRANSCRIPT_TEMPLATE.md`. The filename is the random ID only. Do not write the condition or task into the transcript file's name or header (the scripted turns reveal the condition on their own; that limit is recorded).
5. Hand me the transcripts (and the DC files) in batches; keep `run_sheet.tsv` to yourself until I have written down my codes. Then I compile every file as written (M7), code M1 to M8 per `PREREG_DRAFT.md`, unblind with the key, and write `RESULTS.md`. The coding sheet is committed before unblinding.
Deviations (a model refused to continue, a session dropped, a turn was sent out of order) go in `DEVIATIONS.md` with the transcript ID; a transcript with a deviation is still scored and flagged.
