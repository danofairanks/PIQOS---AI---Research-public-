# Replication material for Addendum A.12 (a Lean repository rebuilt in part)
Source: a public repository from the lab of A.8, at commit `3931bc4` (17 November 2026; the repository was restructured afterwards: `collapse/CE/Main.lean` and `pinn/PINN/Main.lean` are byte-identical to the corresponding files at the later head). The repository's own script `tools/project.py` (read in full before running) was used as its README describes: `check <namespace> <folder> <tag>` rebuilds a folder from scratch in a fresh workspace, rejects banned tokens (the Lean keyword for a declared assumption, `sorry`, `native_decide`, macro and elaborator definitions and similar), and prints each main theorem with its assumption listing. Toolchain: Lean 4.27.0-rc1, Mathlib `fdddb3ea` (the repository's pin). Machine: 4 cores, 15 GB of memory.
Files: `01_collapse_check.json`, `02_pinn_check.json`, `12_lower_check.json` (the three folders that built, with each theorem's statement and assumption listing); `13_upper_check.json` and `14_interval_check.json` (one job at a time; each ends at a module killed by the container's memory limit) with `oom_attempt1/` (the first attempt, four jobs); `10_sha256sums.txt` (before the weight files are copied into the induction folders, so it reports 437 expected misses) and `10b_sha256sums_after_restore.txt` (after the repository's `induction/restore_weights.sh`: no failures); the `*_time.txt` and `00_status*.txt` files (wall times and exit codes). The scratch paths in the logs are those of the scoring container.
