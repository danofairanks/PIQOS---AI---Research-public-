# Control scan of four unrelated authorization libraries (pilot)
Not run by `../run_all.py` (needs the libraries). In a clean virtual environment: `pip install PyJWT==2.15.1 itsdangerous==2.2.0 casbin==1.43.0 pymacaroons==0.13.0`, then `python probes.py > out_probes.json`. The probes test caller-chosen freshness windows and clocks, replay, tamper, wildcard text matching, wrong-type input, downgrade and caller-supplied attributes. Four libraries, Python only, probes written by the paper's author from its own pattern list: a pilot of whether the mechanisms recur outside the specimens, not a sample. Predictions were written before the probes; two missed (PyJWT rejects an unsigned token even when the caller lists that algorithm; a first macaroon-tamper probe was vacuous because it built the credential with the key, and was fixed).
