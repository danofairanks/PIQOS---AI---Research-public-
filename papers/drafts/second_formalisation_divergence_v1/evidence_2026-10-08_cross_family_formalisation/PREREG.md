# PREREG — cross-family second formalisation test (filed before any ChatGPT output exists)
Question: does a second formalisation from a different model family + mutual-entailment check (SMT, z3 5.1.0) detect ambiguity-resolution divergences that a single translator does not flag? (Follows H2 v3.2 / direction leg.)
Design: six plain-English statements (stimuli.json), each with a fixed SMT-LIB signature; formalisation A = Claude (claude_formalisations.json, committed BEFORE the brief is sent); formalisation B = fresh ChatGPT session via BRIEF_CHATGPT.md (no memory, no context). Checker check.py classifies A vs B as equivalent / A stronger / B stronger / incomparable / inconclusive (sound: `unsat` proves entailment; `sat` is a real countermodel; quantified-function cases fall back to fixed candidate interpretations; unresolved = inconclusive). Parsing is restricted to exactly one `(define-fun spec ...)` form; no model-produced code is executed.
Checker self-test (run before the brief; recorded): identical -> equivalent on all six; deliberately varied readings -> S1 A stronger, S2 A stronger, S3 B stronger, S4 B stronger, S5 A stronger, S6 equivalent. My pre-test expectation for S3 was "incomparable"; the checker said B stronger and it is right (gross positive sum <= C implies every prefix net sum <= C); my expectation was wrong.
Known biases: stimuli and formalisation A are both mine, so A is not blind to the intended ambiguities and the same-family arm is NOT run (no blind second Claude pass). The test therefore measures cross-family divergence and detectability only, not which reading is "correct".
Claude's readings (A): S1 exists-C forall-n f<=g+C; S2 strict increase; S3 net prefix sums each <= C; S4 forall student exists exam; S5 strict (1<x<10); S6 positive even.
Predictions for B (ChatGPT) vs A:
 S1 equivalent 75%. S2 equivalent (strict) 55% (else B weaker: non-strict). S3 divergent 75% (most likely B = final net sum <= C, so A stronger; or gross/abs). S4 equivalent 60% (else exists-exam-for-all). S5 equivalent 50% (else inclusive, A stronger). S6 equivalent 98%.
 At least 2 divergences among S1-S5: 80%. At least one divergence where the ChatGPT answer does NOT flag ambiguity in its own `ambiguity` field: 55%. Checker returns `inconclusive` on >=1 pair: 25%.
Scoring (after B arrives): per pair relation; divergence list; self-report vs detection table; any pair where B's formalisation fails validation (format) recorded as invalid, not as divergence.
Decision use: a divergence flags a statement where one reading was silently chosen; absence of divergence is NOT evidence that the reading is correct (shared training distribution: INV-CROSS-LLM-NOT-INDEPENDENT-style limit; two families still share most corpus).
