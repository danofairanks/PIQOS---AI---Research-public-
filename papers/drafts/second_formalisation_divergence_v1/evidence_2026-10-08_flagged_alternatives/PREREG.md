# PREREG — flagged-alternatives test (filed before the scoring script is run)
Hypothesis (from batch 2 K1, formed AFTER seeing batch-2 notes): a translator's self-reported ambiguity note, read as a list of alternative readings, covers the readings that OTHER translators choose, including readings no arm chose (K1 gross). Not a new model run: it re-uses the six existing note sets (ChatGPT, fresh Claude, incognito Claude in batch 1 and batch 2). Arm A (this session) wrote no notes.
Held-out logic: the pattern was noticed on batch-2 K1. Batch 1 (B01, B09, B11, B12, B13) is held out relative to that observation; batch-2 items (E06, E10, K1, K2) are in-sample.
Procedure: (1) For each item, reading labels and reference SMT formulas are fixed in flagged_alt.py (committed with this prereg). (2) Each arm's chosen formalisation is classified by z3 equivalence against the labels (other = no label). (3) Each arm's note is mapped to named labels by a fixed rule: the note names label L if it contains a keyword for L (case-insensitive) AND an alternative cue word (could, may, or, alternative, instead, unclear, rather, ...). Keyword lists are fixed in the script before running. (4) Metric per arm: reading recall = share of (other arm chosen label != this arm's chosen label) cases whose label appears among this arm's named labels; reading precision = share of named labels that some arm chose. (5) Manual review afterwards is reported separately; it does not change the automatic numbers.
Items scored: B01, B09, B12, B13 (reading divergences, batch 1; B11 is a translation error and is reported as non-coverable), E06, E10, K1, K2 (batch 2). Unchosen-but-intended label: K1 gross.
Predictions: Claude arms (fresh and incognito): recall >= 75% on batch-1 items (70%); ChatGPT recall <= 50% (65%); precision of named labels (any arm) <= 50% (60%); K1 gross named by both Claude arms (85%) and by ChatGPT (10%); at least one case where the keyword rule misclassifies a note (manual review disagrees) (60%).
Limits: the keyword rule is crude by design (fixed, not tuned); six note sets; labels are my choice of reading space (not exhaustive); notes are free text from three model chats; no new data.
