Scripts and outputs for `scientisttwo_release_reading_v1.md`. Tables were transcribed by hand from the PDFs (the repository releases no data); page and table numbers are in the draft. No PDF is stored here.
- `host_table_checks.py` / `_output.txt`: arithmetic on the release paper's Tables 3, 5, 7.
- `pdf_keyword_scan.py` / `pdf_keyword_scan_out.json`: keyword presence scan over the 86 PDFs (needs `pypdf`; run on a clone of the site repository).
- `select_sample.py`: the hash rule for the six-paper sample.
- `sample6_checks.py` / `_output.txt`: arithmetic on the six sampled papers' tables.
- `specimen_checks.py` / `_output.txt`: arithmetic on the operator-chosen specimen's tables.
- `dr_schervish_checks.py` / `_output.txt`: equation and table checks for the single paper read in full (section 6c).
