## Amendment 1 (after run 1 of T5; before run 2)
Flaw: in `toys_rl.py` run 1, mode 'fac' (the T5 factorial) never computed the modulation signal (mod=0), so kappa>0 had no effect and the exploration-modulation cell used eps_min only. Evidence: cell means of 00 and 10 are identical (110.2677) and of 01 and 11 identical (123.808) in `out_t5_run1_INVALID.txt`. Run 1 of T5 is INVALID and is not scored. Fix: mode 'fac' uses mod = |tanh(0.5 d)| as in MEM-A. Run 2 uses the same prereg design (D5) and the same seeds.
## Amendment 2 (after run 1 of T4; before run 2)
Flaw: the tuned kappa for both MEM-A and HRL-sched was the largest grid value (4), i.e. the optimum may lie beyond the grid, which disadvantages whichever agent benefits more. Run 2 extends the grids to equal size 15 for all three agents: MEM-A and HRL-sched kappa in {0.5,1,2,4,8} x eps_max in {0.15,0.3,0.5}; HRL eta0 in {0.05,0.1,0.2,0.4,0.8} x eps in {0.02,0.05,0.1}. Evaluation seeds unchanged (2000-2029); tuning seeds unchanged (1000-1009). Run 1 results are kept (`out_t4_run1.txt`) and reported alongside.
## Amendment 3 (reading rule for D4; written before run 2)
Run 1 produced an outcome D4 did not enumerate: HRL-sched was BETTER than MEM-A by 2.3 SE (P4a held, 14 SE). Rule for run 2: if HRL-sched is better than MEM-A by > 2 SE, or within 1 SE, report "defeated at scope (a simple matched rival explains and does not trail MEM-A)"; if it trails by > 2 SE, "not reached". Between 1 and 2 SE on either side: "inconclusive". Disclosure: the schedule function of HRL-sched (C/9, quadratic) is not the same function as A = tanh(0.5 d); the comparison shows a simple alternative monotone schedule matches or beats A at this toy scale, not that A and the schedule are equivalent.
