Method = the project's standard (see `../pre_execution_gate_counter_models_v1.md` in this repository): extract claim forms; decide whether enough is specified to build on; fix defeat conditions in writing first; generic toys; results labelled **defeated at scope**, **not reached**, or **blocked**; test-vocabulary closure (toys are written in the papers' own definitions: Eqs. (2)-(4), (6)-(9), (13)-(14), (17), (25)-(26) of arXiv 2609.20437 as I read them; no outside theory is used to define a MEM term). Fidelity rule: a toy attacks a claim only as the papers state it; where the paper already specifies the stronger test, the claim form is dropped, not attacked. Same-family caveat: one reader, no independent blind pass yet; an amendment section at the bottom (never edits) records any flaw found after a run.

## Toys and defeat conditions (fixed now)
**T1 (CF1).** Instances: 10^4 random draws, M=5..40 semblions, dims 8..32. (i) sim = dot product; (ii) sim = cosine with unit-normalised inputs; (iii) sim = Gaussian RBF. Counter-model: a classifier on the concatenated input z=[h;b]: linear scores w_m·z + c_m with w_m=[a_s mu_m ; b_b rho_m], c_m = x_v v_m for (i),(ii); additive-kernel machine k = a_s k1 + b_b k2 + c_m for (iii). **Defeat condition D1:** the CF1 contrast ("unlike ordinary classification") is DEFEATED AT SCOPE (formal level) if max |u_m - u'_m| < 1e-9 and the argmax agrees on 100% of instances for all three sims. Survives if any instance differs. Prediction 0.97 defeated.
**T2 (CF2).** Implement Eq. 8-9, 13-14 exactly (TopK, lateral priming q_m = sum_n L_mn [u_n]+, u~ = u + lam_L q, softmax over the candidate set at temperature tau_c, h^ = sum a_m mu_m, h_eff = (1-lam) h_ff + lam h^). Counter-model: sparse (top-k) softmax attention readout over the same memory with the same score function, residual mixing with the same lam. **D2:** DEFEATED AT SCOPE (formal level only) if max |h_eff - h_eff'| < 1e-12 on all instances. Note (scope of the defeat): it shows the equations do not encode what separates re-entry from an attention-plus-residual step; the papers' separating feature is provenance of mu_m (receptor-grounded) and physical lower-level maps, which are not in the formalism; so D2 does not defeat the grounding claim, which stays unbuilt (CF6 note). Prediction 0.95 defeated.
**T3 (CF3).** Environment: one allostatic variable n in [0,10] (tolerated [3,10]), actions work (task reward 1, n-=1) and recharge (n+=2), noise, episode length 200, death penalty only for agent (a). Agents: (a) tabular Q-learning with the battery bucket as an observation feature and external reward (task reward - death penalty); (b) MEM-coupled: state includes n, internal reward -Delta C (Eq. 4, one-sided quadratic), learning rate eta = eta0 (1 + kappa |A|) (Eq. 17), A = tanh(w d + c) (Eq. 3); (c) decoupled telemetry: same as (a) but trained without n in its state and then given n readable but unused. Test per §6.3: disconnect = reading replaced by constant "full" for 60 steps, then restored; measure recharge frequency per 60-step window. Pass criterion (mine, from the paper's wording "systematically change ... and recover them"): recharge frequency changes by >= 0.20 on disconnect and returns within 0.05 of the pre-disconnect value after restore, with no new external reward. **D3:** the disconnect/restore test is DEFEATED AT SCOPE as a discriminator between coupled interoception and telemetry-as-observation if (a) passes. Additional (not the paper's §6.3 test): correlation of eta(t) with |A(t)|: predicted ~1 for (b), 0 for (a),(c): if so, a different criterion (modulation of learning) does separate them (result against a one-sided reading). Predictions: (a) passes 0.85; (c) fails 0.95; eta-|A| separation 0.95.
**T4 (CF4).** Environment: two regulated variables (energy, temperature) with disturbances and a non-stationary food-location change every 100 episodes (adaptation matters); tabular Q; 30 seeds x 300 episodes; metric = cumulative regulatory cost AUC (Eq. 4) per seed. Agents with equal tuning budget (kappa or kappa' chosen by grid on a separate set of 10 tuning seeds, same grid size): HRL (fixed eta0, eps0; reward -Delta C); MEM-A (eta = eta0(1+kappa|A|); eps = eps_min + (eps_max - eps_min)|A|); HRL-sched (eta = eta0(1+kappa' C/C_ref); eps = eps_min + (eps_max-eps_min) min(1, C/C_ref); no A). **D4:** the claim "a resource-matched rival cannot explain MEM's affect-modulation result" is DEFEATED AT SCOPE if (P4a holds) MEM-A beats HRL by > 2 SE AND (P4b) |mean(HRL-sched) - mean(MEM-A)| <= 1 SE. NOT REACHED if HRL-sched stays worse by > 2 SE. Predictions: P4a 0.6; P4b given P4a 0.7.
**T5 (CF5).** Same environment, 2x2 factorial of two independent modulators: F1 = learning-rate modulation on/off (kappa>0 vs 0), F2 = exploration modulation on/off; 30 seeds each cell; outcome = cumulative regulatory cost. Compute the interaction contrast (cell11 - cell10 - cell01 + cell00) on the raw scale and on the log scale with bootstrap CIs. **D5:** the claim that an interaction among components is a specific signature (the basic unit of inference) is DEFEATED AT SCOPE if the interaction CI excludes 0 on one scale and includes 0 on the other (the signature depends on the measurement scale, with no coupling between the two modulators beyond a shared input). Prediction 0.6.
Blocked, not built: CF6, CF7.

## What would cut against a one-sided reading (stated now, so it counts if it happens)
If P4a holds and P4b fails (tuned schedule does not close the gap), CF4 is NOT REACHED and the MEM-specific claim for the affect-modulation component stands as a distinguishing feature against homeostatic RL at this toy scale. If the eta-|A| criterion separates coupled from telemetry agents, the paper's broader definition of coupling (modulation of learning) is sound even though its §6.3 test alone is not. Both are reported in the same register as defeats.
