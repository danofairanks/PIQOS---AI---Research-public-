Tools

pip install-able Python packages — reference implementations, classifiers, and audit utilities. Each links to its own README for install instructions, test counts, and documented limitations.

basin_depth

Reference implementation of the Noether-Temporal Coherence Test Protocol — corpus preprocessing through the final basin-depth metric.

bifp

Structured audit tool for the Basin-Immune Falsification Protocol — persistent, criterion-by-criterion audit records across Phase 0–6.

attractor_scan

Classifier for the seven defensive maneuvers and semantic-laundering cases, with matched spans over text or a JSONL corpus.

debasinizer

Sibling classifier for the resonance-vocabulary register documented in the "Mind Viruses" paper, plus a self-coherence-assertion detector.

case_scaffold

Scaffolding generator and structural linter for this repository's own case_studies/ house format.

verification_lint

Content-level evidentiary-gap scanner — unattributed quotes, uncited high-precision statistics, missing scoping sections.

paper_rigor

Domain-agnostic paper-rigor scanner — placeholder phrases, falsifiability, citation mix, credentialing, consensus claims, missing limitations.

research_mcp

Live MCP server exposing all five other packages' agent-tool surfaces (19 tools total), tested over the real wire protocol.
