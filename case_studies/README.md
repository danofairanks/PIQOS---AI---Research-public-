# Case Studies

Real-time applications of the frameworks in [`../papers/`](../papers/) to
dated, publicly-reported events, as they happen. Where `papers/` holds
the theory and `protocols/` holds the reproducible measurement
methodology, this directory holds the framework run against a live
specimen — a diagnostic snapshot, not a claim that ages into a
permanent thesis.

## Naming convention

`<date>_<specimen_slug>.md`, e.g. `2026-07-27_ssi_nvidia_partnership.md`.
The date is the date of analysis (recorded in the document header
alongside the event date if they differ).
